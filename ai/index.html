// keystroke recorder

NotBot

NotBot records your keystrokes as you write, then gives you a link so anyone can watch you type it. Real cadence, real pauses, real typos. Proof of authorship. No backend. Nothing stored, nothing to leak, nothing to maintain. The message lives entirely inside the link.

// pull requests, for designers

Graft

A designer-focused way to contribute to Git. Create branches in custom edit areas, free from technical friction like auth and routing. Editing is scoped so you can't touch core backend infrastructure. PRs are automatically annotated to smooth the handoff to development.
